🔁 科目B 反復トレーニング

擬似言語のトレース・穴埋めとセキュリティのケース問題 全80問を、本試験と同じ選択式で解くドリルです。間違えた問題は同じセッション内で何度でも戻ってきて、2回連続で正解するまで「定着」になりません。解いた記録はこの端末に保存されます。初めての人は、先に🧭解き方ガイドで「型」をつかむのが近道です。

🧭 解き方ガイド 🎯 反復ドリル 📊 習熟マップ 📖 トレースのコツ 🔗 復習リンク

🔄 このドリルの回し方

  • 選択肢をタップするとその場で正誤とトレース付き解説が出ます。
  • 詰まったら💡ヒントを開く：「着眼点」→「組み立て」の2段階。いきなり答えを見るより、ヒントで1手だけ助けてもらって自力で解くほうが力がつきます。
  • 間違えた問題は数問後にもう一度出ます（正解するまで繰り返し）。
  • 2回連続で正解すると「定着」。間違えると定着度は0に戻ります。
  • おすすめは、まず「全部・10問」で1周 → 2周目からは🤔弱点だけで回すこと。
  • 本試験の時間感覚は1問5分。結果画面の所要時間で確かめられます。

🧭 解き方ガイド — どこから手を付ける？

科目Bの問題は実は3タイプだけ。それぞれ「最初に見る場所」と「手の動かし方」が決まっていて、型どおりに進めればひらめきは要りません。各タイプの実演を1回ずつ動かしてみてください。

タイプ1：トレース問題 —「実行後の値はどれか」

コードを見て「読める気がしない」と固まる必要はありません。読むのではなく、コンピュータのふりをして1行ずつ実行し、変数の値を表に書くだけです。

  1. 何を答えるかを先に確認する（最終値？出力？実行回数？）。
  2. 登場する変数を書き出して表の見出しにする。
  3. 1行ずつ実行して表を埋める。ループも面倒がらず全周書く。
  4. 出た値を選択肢と照合。添字と回数をもう一度だけ見直す。
▼ 実演：「▶ 次の一手」を押すたびに1手ずつ進みます

紙での書き方の詳細は 9-4 トレース表の書き方 へ。

タイプ2：穴埋め問題 —「空欄に入れる字句はどれか」

空欄問題は「思いつく」問題ではなく、選択肢を空欄に入れて動かしてみる（代入法）問題です。コードを完全に理解できなくても、目的と食い違う選択肢を消していけば残ります。

  1. 「何をするプログラムか」の説明文を先に読む（コメントや設問文に必ず書いてある）。
  2. 空欄の行が何をする行か、前後の行から見当を付ける。
  3. いちばんそれっぽい選択肢を空欄に入れて小さくトレースする。
  4. 目的どおり動けば正解候補。残りの選択肢は「なぜダメか」を一言で消す。
▼ 実演：空欄に入れる字句はどれ？
タイプ3：セキュリティのケース問題 —「最も適切なものはどれか」

ケース問題は知識の暗記より消去法が効きます。「最も適切」と聞かれたら、まず明らかにおかしい選択肢を消し、残った2択を原則に照らして比べます。

  1. 状況を整理する：誰が・何をして・何が起きた？
  2. 問われ方を確認する（取るべき行動？原因？再発防止策？）。
  3. 極端な選択肢（放置・全面禁止・独断）をまず消す。
  4. 残りを原則（別経路確認・最小権限・職務分離・多要素・隔離と報告）と照合。
▼ 実演：消去法の進め方

記号意味
←右の値を左の変数に入れる（代入）
≦ ≧ ≠以下・以上・等しくない
mod割った余り（7 mod 3 は 1）
÷割り算。切り捨てるかは問題文の注記を見る
and / or / notかつ・または・〜でない
{1, 2, 3}配列。要素番号は1始まりが基本（注記を確認）
a[i]配列aのi番目の要素
/* … */コメント。プログラムの目的が書いてある宝の山
○ f(引数)関数・手続きの定義
return呼び出し元に値を返して終わる
