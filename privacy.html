紙の地球儀 投稿ツール（個人用）

このツールについて

「紙の地球儀 投稿ツール」は、運営者が自分の YouTube チャンネルに、自分で作った動画を予約投稿するためだけに使う個人用のツールです。運営者以外の人は使いません。

使う情報

YouTube API サービスを通じて、次の範囲だけを扱います。

  • 投稿先が正しいかを確かめるための、運営者のチャンネル名と ID
  • 運営者が作った動画・サムネイル・題名・説明文・再生リストのアップロードと、公開日時の設定

運営者以外の人の情報は、集めることも扱うこともありません。

保存と共有

  • Google のログイン情報（アクセス トークン）は、運営者の PC の中にだけ保存します。外部のサーバーには送りません。
  • 扱った情報を、第三者に渡したり売ったりすることはありません。
  • 広告や分析のためには使いません。

アクセスの取り消し

このツールに与えた権限は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

YouTube と Google の規約

このツールは YouTube API サービスを使っています。利用には YouTube 利用規約が適用され、Google によるデータの扱いは Google プライバシー ポリシーに従います。
